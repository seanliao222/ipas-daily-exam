第 2 題 L22 L22102 機率分佈與資料分佈模型
在隱馬可夫模型（Hidden Markov Model, HMM）中，「隱藏」（Hidden）指的是什麼？
A模型的轉移機率是隱藏的
B模型內部的狀態（States）序列是無法直接觀測到的，只能透過可觀測的輸出序列來推斷
C模型的輸出機率是隱藏的
D模型的初始狀態分佈是隱藏的
✅ 正確答案：B
">隱馬可夫模型（HMM）是一種用於描述含有隱藏狀態的馬可夫過程的統計模型。它包含兩個序列：一個是無法直接觀察到的隱藏狀態序列（遵循馬可夫鏈，即當前狀態只依賴於前一個狀態），另一個是可以觀察到的輸出符號序列。模型的假設是，每個輸出符號的生成機率僅僅依賴於當前的隱藏狀態。由於我們只能觀察到輸出序列，而無法直接知道系統處於哪個隱藏狀態，因此這些狀態被稱為「隱藏」的。HMM 的典型任務包括：給定模型和觀測序列，計算該序列出現的機率；給定模型和觀測序列，找出最可能的隱藏狀態序列（解碼問題）；給定觀測序列，學習模型的參數（轉移機率、輸出機率、初始狀態分佈）。HMM 廣泛應用於語音識別、自然語言處理（如詞性標註）、生物資訊學等領域。

A將不同模態完全分開處理，不進行任何交互。
B學習到的表示向量中，不同的維度或子空間對應到數據中潛在的、可解釋的、相對獨立的變異因素。

第 7 題 L22 L22103 假設檢定與統計推論
卡方獨立性檢定（Chi-squared Test of Independence）主要用於檢定什麼？
A單一樣本的平均數是否等於某特定值
B兩個類別型變數之間是否存在統計上的關聯性（是否相互獨立）
C三個或以上樣本的平均數是否相等
D樣本數據是否服從常態分佈
✅ 正確答案：B
">卡方檢定有多種應用，其中獨立性檢定是用於分析兩個類別型變數的關係。它基於觀察到的兩個變數交叉分類的列聯表（Contingency Table）。虛無假設 H0 是這兩個類別變數相互獨立（沒有關聯）。檢定透過比較列聯表中的觀測頻數（Observed Frequencies）與在獨立假設下計算出的期望頻數（Expected Frequencies）之間的差異來計算卡方統計量。如果差異足夠大（卡方值大於臨界值或 P 值小於 α），則拒絕 H0，認為兩個變數之間存在統計上的關聯性。例如，用來檢定吸菸習慣與是否罹患某種疾病之間是否有關聯。

第 11 題 L21 L21301 數據準備與模型選擇

A均方誤差（MSE）、平均絕對誤差（MAE）
B準確率（Accuracy）、精確率（Precision）、召回率（Recall）、F1 分數

✅ 正確答案：B
">混淆矩陣是視覺化和總結分類模型預測結果的表格。對於二元分類，它包含四個值：真正例（TP）、假正例（FP）、真負例（TN）和假負例（FN）。基於這四個值，可以計算出多種常用的分類評估指標： 準確率 Accuracy = (TP + TN) / (TP + FP + TN + FN) 精確率 Precision = TP / (TP + FP) 召回率 Recall = TP / (TP + FN) F1 Score = 2 * (Precision * Recall) / (Precision + Recall) 假正例率 FPR = FP / (FP + TN) 等。選項A和C是回歸指標。
